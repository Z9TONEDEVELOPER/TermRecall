# Примеры расчётов, совпадающие с кодом

Код: `src/TermRecall.Domain/Algorithms/Sm2Algorithm.cs` и `ReviewCalendar.cs`.

История в приложении хранит текст из `Sm2Result.Explanation`. Ниже те же подстановки.

## Пример курсовой работы

Начало: \(EF = 2{,}5\), \(I = 0\), \(n = 0\).

### \(q = 4\)

```
EF' = 2.5 + (0.1 − (1) × (0.08 + (1) × 0.02)) = 2.5 + (0) = 2.5
q = 4 ≥ 3: первое успешное повторение, I = 1 день, n = 1.
```

Состояние: \(EF = 2{,}5\), \(I = 1\), \(n = 1\).

### \(q = 5\)

```
EF' = 2.5 + (0.1 − (0) × (0.08 + (0) × 0.02)) = 2.5 + (0.1) = 2.6
q = 5 ≥ 3: второе успешное повторение, I = 6 дней, n = 2.
```

Состояние: \(EF = 2{,}6\), \(I = 6\), \(n = 2\).

### \(q = 4\)

```
EF' = 2.6 + (0.1 − (1) × (0.08 + (1) × 0.02)) = 2.6 + (0) = 2.6
q = 4 ≥ 3: I = round(6 × 2.6) = round(15.6) = 16 дн., n = 3.
```

Состояние: \(EF = 2{,}6\), \(I = 16\), \(n = 3\).

Тест `CourseworkSequence_UsesDocumentedNumbers` проверяет числа. Тест `CourseworkReviews_ArePersistedWithDates` проводит ту же последовательность через базу.

Даты при часовом поясе UTC и первом ответе 2026-11-05 09:00:

| Ответ | Следующий срок |
|---|---|
| первый | 2026-11-06 00:00 UTC |
| второй | 2026-11-12 00:00 UTC |
| третий | 2026-11-28 00:00 UTC |

Если после третьего ответа открыть приложение 2026-12-01, термин остаётся в очереди просроченных. Интервал по-прежнему 16, статус не становится «освоен» сам по себе.

## Неуспех и повторный старт

Состояние \((2{,}5,\ 16,\ 3)\), оценка 2:

\[
EF' = 2{,}5 - 0{,}32 = 2{,}18,\quad n' = 0,\quad I' = 1
\]

Оценка 1 из того же исходного состояния \((2{,}5,\ 16,\ 3)\):

\[
EF' = 2{,}5 - 0{,}54 = 1{,}96,\quad n' = 0,\quad I' = 1
\]

Следующая оценка 5 уже из \((1{,}96,\ 1,\ 0)\):

\[
EF' = 1{,}96 + 0{,}1 = 2{,}06,\quad n' = 1,\quad I' = 1
\]

Интервал снова 1, потому что успешных повторений после сброса ещё не было. Это первое успешное повторение новой серии. Тест: `AfterFailure_NextSuccessIsTreatedAsFirstAgain`.

## Нижняя граница лёгкости

\(EF = 1{,}3\), \(q = 0\):

\[
1{,}3 - 0{,}8 = 0{,}5 \rightarrow EF' = 1{,}3
\]

\[
n' = 0,\quad I' = 1
\]

## Округление

| Сырое значение | Результат |
|---|---|
| 15,6 | 16 |
| 15,4 | 15 |
| 10,5 | 11 |
| 0 | 1 |

10,5 специально отличается от банковского округления к чётному, которое в .NET используется по умолчанию. В TermRecall половина округляется от нуля.

## Часовой пояс

Ответ 2026-03-10 22:30 UTC в поясе Europe/Moscow — это 2026-03-11 01:30. Плюс один день даёт местную полночь 2026-03-12, то есть 2026-03-11 21:00 UTC.

Ответ 2026-03-28 23:30 UTC в Europe/Berlin попадает на местное 29 марта, до перевода часов. Плюс один день — полночь 30 марта уже в летнем времени. Срок остаётся календарным 30 марта, а не «плюс 24 часа».

## Индекс эффективности

При \(P = 80\), \(R = 50\), \(C = 20\) и весах \(0{,}5,\ 0{,}2,\ 0{,}3\):

\[
E = 0{,}5\cdot 80 + 0{,}2\cdot 50 + 0{,}3\cdot 20 = 40 + 10 + 6 = 56
\]

Прогресс интервала при \(I = 6\) и пороге 21:

\[
M = 6 / 21 \cdot 100 \approx 28{,}57
\]

При \(I = 40\) и том же пороге \(M = 100\), потому что значение ограничено сверху. Это доля пути до порога, не вероятность припоминания.

## Что смотреть в приложении

После оценки карточки над следующей карточкой появляется строка вида «Интервал a → b дн., EF x → y». В карточке термина и в журнале хранится полный текст формулы из этого файла. Журнал открывается из статистики и из карточки термина.
