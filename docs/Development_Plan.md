# План разработки

План из постановки выполнен по слоям, а не одним файлом.

1. Проектирование. Выбраны .NET 10 и Avalonia 11.3.9, слои Domain / Application / Infrastructure / App и отдельные головы Desktop, Android, iOS.
2. Каркас. Решение собирается, общий UI живёт в библиотеке, desktop запускает его через `StartWithClassicDesktopLifetime`.
3. База. Миграция `001_init`, репозитории, начальный набор терминов C#.
4. SM-2. Отдельный модуль и тесты на контрольные числа, минимум EF, сброс серии, округление и даты.
5. Сценарии. Наборы, термины, очередь, история, статистика, настройки, CSV, JSON, резервная копия.
6. Интерфейс. Четыре раздела, карточка с переворотом, оценки 0–5, светлая и тёмная темы.
7. Связка. ViewModel вызывает сервисы, ответ пишется в ту же базу, из которой строится очередь.
8. Проверка. 24 теста домена, 3 теста проверок ввода, 7 интеграционных тестов SQLite. Desktop-проект собирается.
9. Мобильные головы. Проект iOS собран для симулятора `iossimulator-arm64`. Проект Android готов к сборке, но workload `android` в системный SDK ставится только с правами администратора. Команды записаны в README.

Дальше, без смены ядра: миграция для изображений и аудио, обмен библиотекой между устройствами поверх уже существующего JSON.
