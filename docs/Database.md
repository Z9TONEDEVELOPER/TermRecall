# База данных

Файл SQLite, режим WAL, внешние ключи включены. Пул соединений отключён: у приложения одно долгоживущее соединение, а восстановление копии должно видеть актуальную страницу файла.

## Таблицы

### categories

| Поле | Смысл |
|---|---|
| id | GUID |
| name | уникальное имя без учёта регистра |
| color | цвет метки, `#RRGGBB` |

### decks

Набор терминов: id, name, description, created_at, updated_at. Удаление набора удаляет его термины.

### terms

Карточка и состояние SM-2.

| Поле | Смысл |
|---|---|
| title, definition | обязательные |
| example, explanation | могут быть пустыми |
| category_id | необязательна, при удалении категории становится NULL |
| deck_id | обязателен |
| created_at, last_reviewed_at, next_review_at | UTC |
| interval_days | целые дни, не меньше 0 |
| ease_factor | не меньше 1.3 |
| repetition_count | успешные повторения подряд |
| status | 0 новый, 1 изучается, 2 повторяется, 3 освоен, 4 сложный |
| lapse_count | число неуспешных ответов |

Индексы: набор, срок повторения, статус, название.

### review_history

Одна строка на ответ. Хранит оценку, прежний и новый интервал, прежний и новый EF, длительность ответа в миллисекундах, число успешных повторений до и после, текст подстановки формулы. При удалении термина история удаляется вместе с ним. Правка текста термина историю не трогает.

### user_settings

Одна строка с `id = 1`: лимиты, напоминание, тема, порог освоения, три веса индекса, имя, порог EF для сложных терминов.

### schema_migrations

Имя применённого SQL-файла и время. Новый файл `Database/Migrations/*.sql` применяется один раз при запуске.

## Первый запуск

Если наборов ещё нет, записываются четыре набора по C# и .NET, категории и термины со статусом «новый». Учебной истории при этом нет: статистика начинается с реальных ответов.

## Копия и восстановление

Копия снимается через `BackupDatabase`, поэтому в неё попадает согласованное состояние, а не полузаписанный WAL. Восстановление копирует страницы во открытое соединение. Перед заменой файл копии открывается и проверяется на наличие `schema_migrations`.

Сброс статистики удаляет историю и возвращает терминам EF 2.5, нулевой интервал и статус «новый». Названия и определения остаются.
