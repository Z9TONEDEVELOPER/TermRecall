# Алгоритмы

Подробные формулы и ограничения — в `Mathematical_Model.md`. Здесь — где какой код лежит.

| Задача | Тип |
|---|---|
| Шаг SM-2 | `Sm2Algorithm` |
| Местная полночь срока | `ReviewCalendar` |
| Статус после ответа | `TermStatusEvaluator` |
| P, Q, M, R, C, E | `LearningAnalytics` |
| Серия дней | `StreakCalculator` |
| Очередь на сегодня | `ReviewQueuePlanner` |
| Запись ответа и истории | `ReviewService` |
| Сводка экранов | `DashboardService`, `StatisticsService` |

Очередь:

1. Просроченные, более ранний срок раньше. При равном сроке меньший EF раньше.
2. Термины на сегодня.
3. Новые, не больше оставшегося дневного лимита новых и общего лимита повторений.

Режим «сложные» не подмешивает новые карточки и может показать сложный термин до его срока. Режим «только новые» берёт ещё не отвеченные карточки. Лимит можно обойти отдельной командой «сверх дневного лимита»: просроченные из-за лимита не помечаются изученными.

Динамика освоения на графике восстанавливается из истории: на каждую дату считается, у скольких терминов последний ответ к этой дате был успешным, с числом повторений не меньше 2 и интервалом не меньше порога. Это снова прогресс по интервалам, не вероятность.
